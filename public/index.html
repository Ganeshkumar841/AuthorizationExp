RBAC Web Client & Token Guide

Understand the 4 steps of what a web application does after receiving a JWT token.

What happens after you get the token? (The 4 Lifecycle Steps)

1 Store the Token

Save it in application memory, or browser storage (like cookies / sessionStorage) so it persists on page refreshes.

2 Decode & Read Role

Read user details (`role`, `username`, expiration) to personalize the UI and show permitted sections.

3 Attach to Every Call

Send it in the HTTP header:
Authorization: Bearer <token> on every protected fetch.

4 Handle Logout / Expiry

If the token expires or the server returns 401, clear the token and automatically redirect back to login.
